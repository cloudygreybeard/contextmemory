# Conversation Persistence System Design

## Overview

This document outlines the design for a conversation persistence system that preserves full AI conversation context before truncation/summarization, enabling continuous memory across context windows.

## Core Data Structures

### 1. Conversation Checkpoint

```go
type ConversationCheckpoint struct {
    // Metadata
    ID             string            `json:"id"`
    ConversationID string            `json:"conversationId"`
    Name           string            `json:"name"`
    Timestamp      time.Time         `json:"timestamp"`
    
    // Content
    Title            string   `json:"title,omitempty"`
    Phase            string   `json:"phase,omitempty"`
    Content          string   `json:"content"`          // Full conversation export
    KeyContext       []string `json:"keyContext"`       // Summary points
    NextSteps        []string `json:"nextSteps"`        // Planned actions
    TruncationPoint  string   `json:"truncationPoint"`  // Where context was cut
    
    // Classification
    AutoGenerated    bool              `json:"autoGenerated"`
    CheckpointType   string            `json:"checkpointType"`  // full, incremental, summary
    Labels           map[string]string `json:"labels"`
    Namespace        string            `json:"namespace"`
}
```

### 2. Conversation Thread

```go
type ConversationThread struct {
    ID          string    `json:"id"`
    Title       string    `json:"title"`
    StartTime   time.Time `json:"startTime"`
    LastUpdate  time.Time `json:"lastUpdate"`
    
    // Relationship
    ParentThread *string   `json:"parentThread,omitempty"`  // For conversation forks
    ChildThreads []string  `json:"childThreads,omitempty"`  // Related conversations
    
    // Metadata
    Project     string            `json:"project,omitempty"`
    Phase       string            `json:"phase"`
    Status      string            `json:"status"`  // active, archived, completed
    Labels      map[string]string `json:"labels"`
    
    // Checkpoints
    Checkpoints []string `json:"checkpoints"`  // Ordered list of checkpoint IDs
    
    // Context Tracking
    TotalMessages    int    `json:"totalMessages"`
    ContextWindows   int    `json:"contextWindows"`  // Number of truncations
    EstimatedTokens  int    `json:"estimatedTokens"`
}
```

### 3. Context Snapshot

```go
type ContextSnapshot struct {
    ID           string    `json:"id"`
    ThreadID     string    `json:"threadId"`
    Timestamp    time.Time `json:"timestamp"`
    
    // Context Data
    Messages     []Message          `json:"messages"`     // Raw message history
    SystemPrompt string             `json:"systemPrompt"`
    Variables    map[string]string  `json:"variables"`    // Environment, settings
    
    // Token Management
    TokenCount      int    `json:"tokenCount"`
    MaxTokens       int    `json:"maxTokens"`
    TruncationRisk  bool   `json:"truncationRisk"`  // Approaching limit
    
    // Triggers
    TriggerType     string `json:"triggerType"`     // manual, automatic, threshold
    TriggerReason   string `json:"triggerReason"`   // Why snapshot was taken
}
```

### 4. Message Structure

```go
type Message struct {
    ID        string            `json:"id"`
    Role      string            `json:"role"`        // user, assistant, system
    Content   string            `json:"content"`
    Metadata  map[string]any    `json:"metadata"`
    Timestamp time.Time         `json:"timestamp"`
    
    // Function Calls (for assistant messages)
    ToolCalls []ToolCall `json:"toolCalls,omitempty"`
    
    // Relationship
    ReplyTo   *string `json:"replyTo,omitempty"`   // Message being replied to
    EditedAt  *time.Time `json:"editedAt,omitempty"`
}

type ToolCall struct {
    ID       string         `json:"id"`
    Name     string         `json:"name"`
    Args     map[string]any `json:"args"`
    Result   any            `json:"result,omitempty"`
    Error    *string        `json:"error,omitempty"`
    Duration int64          `json:"duration"`  // milliseconds
}
```

## Retrieval Patterns

### 1. Context Reconstruction

```go
func ReconstructContext(conversationID string, targetTimestamp time.Time) (*ContextSnapshot, error) {
    // 1. Find conversation thread
    thread := GetConversationThread(conversationID)
    
    // 2. Find relevant checkpoints before target time
    checkpoints := GetCheckpointsBeforeTime(conversationID, targetTimestamp)
    
    // 3. Find incremental snapshots since last checkpoint
    lastCheckpoint := checkpoints[len(checkpoints)-1]
    snapshots := GetSnapshotsSince(conversationID, lastCheckpoint.Timestamp, targetTimestamp)
    
    // 4. Reconstruct full context
    return MergeCheckpointsAndSnapshots(checkpoints, snapshots)
}
```

## Automation Triggers

### 1. Context Window Monitoring

```go
type ContextMonitor struct {
    MaxTokens        int     `json:"maxTokens"`
    WarningThreshold float64 `json:"warningThreshold"`  // 0.8 = 80% of limit
    CriticalThreshold float64 `json:"criticalThreshold"` // 0.95 = 95% of limit
}

// Trigger conditions
- tokenCount >= maxTokens * warningThreshold  → Create incremental snapshot
- tokenCount >= maxTokens * criticalThreshold → Create full checkpoint
- New conversation starts                      → Create thread
- Conversation idle > 1 hour                   → Archive thread
```

### 2. Event-Based Triggers

```go
type EventTrigger struct {
    EventType   string `json:"eventType"`
    Condition   string `json:"condition"`
    Action      string `json:"action"`
}

// Examples:
- Event: "tool_call_error"      → Action: "create_debug_checkpoint"
- Event: "project_milestone"    → Action: "create_milestone_checkpoint"
- Event: "conversation_branch"  → Action: "create_fork_checkpoint"
- Event: "session_end"          → Action: "create_handoff_checkpoint"
```

## Usage Examples

### Creating a Manual Checkpoint

```bash
@contextmemory checkpoint \
  --conversation-id "mcp_implementation_2025_09_29" \
  --title "MCP Server Complete" \
  --phase "implementation-complete" \
  --key-context "SDK migration successful, Cursor integration working" \
  --next-steps "Create installation docs, Deploy to production"
```

### Searching Conversation History

```bash
@contextmemory search \
  --query "debugging MCP integration issues" \
  --conversation-id "mcp_implementation_2025_09_29" \
  --labels "phase=debugging"
```

### Reconstructing Context

```bash
@contextmemory context reconstruct \
  --conversation-id "mcp_implementation_2025_09_29" \
  --target-time "2025-09-29T14:00:00Z"
```

This design provides a comprehensive foundation for preserving and retrieving AI conversation context across unlimited time horizons.
